HOW TO INSTALL
1. Open Chrome and go to chrome://extensions
2. Turn ON "Developer mode" (top right)
3. Click "Load unpacked" and pick this folder (football-scores)
4. Click the puzzle-piece icon in Chrome's toolbar and pin "Football Scores"
5. Click the icon, then click any match to see goals, cards and substitutions

GOAL ALERTS (v1.1)
Premier League only. Use the bell button in the popup to turn alerts on/off.
After updating files: chrome://extensions -> click the reload arrow on Football Scores.

# Updates

Newest version first. See `BUGS.md` for bug details.

## 1.2.0

- Added tabs: **Premier League**, **La Liga · Bundesliga · Serie A · Ligue 1**, and **Europe** (Champions, Europa and Conference League).
- The popup remembers the last tab you used.
- Only the leagues in the open tab are loaded, so fewer requests are made.
- Fixed: halftime now shows **HT** instead of a frozen 45'+ clock. The live clock resumes in the second half, and finished matches show **FT** (AET / Pens after extra time or penalties).

## 1.1.0

- Added Premier League goal notifications, with the scorer and minute when available. Other leagues don't trigger alerts.
- Added a bell button in the popup to turn alerts on or off.
- Added an extension icon.
- The extension now checks the Premier League once a minute in the background while Chrome is open.

## 1.0.0

- First release.
- Scores for the Premier League, La Liga, Bundesliga, Serie A, Ligue 1, Champions League, Europa League and Conference League.
- Click a match to see goals, yellow and red cards, and substitutions.
- Date buttons and a date picker, a manual refresh button, and a 60-second auto-refresh on today's view.
- Light and dark mode.
